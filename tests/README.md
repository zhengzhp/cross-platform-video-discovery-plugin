# 测试目录

使用 Node 内置测试框架；`npm test` 先构建，再执行 `tests/*.test.mjs`。

- `core.test.mjs`：合成候选规范化、排序与查询，临时 SQLite 存储、事务回滚、批次编号、反馈范围与撤销重算、取消后的基础锁释放及 schema 版本保护。
- `lock.test.mjs`：独立子进程竞争同一用户锁、正常释放与 SIGKILL 后恢复。
- `fixtures/lock-worker.mjs`：锁测试子进程，仅使用测试创建的数据库。

默认离线，不调用浏览器、不使用账号或密钥、不依赖视频站，不创建仓库内数据库。没有空测试或跳过断言。

浏览器假执行器、来源页面夹具、实际宿主与真实来源冒烟尚未实现；不能用核心离线测试替代这些检查。PID 复用与挂起活进程恢复仍是基础锁的已知边界。

验证分层、命令与结果记录要求见 [验证规范](../docs/verification.md)。后续自定义平台配置测试随对应业务加入，不在当前提前实现配置加载。
